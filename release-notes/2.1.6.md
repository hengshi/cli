# HENGSHI CLI 2.1.6

Released: 2026-06-16

## Highlights

- Improved dashboard chart authoring for subject measure charts.
- Hardened chart patch behavior to avoid destructive mutations and invalid zoom overrides.
- Fixed chart option handling so subject measure identifiers are preserved correctly.
- Updated bundled dashboard and HQL skills with the latest chart-axis and dashboard-plan guidance.
- Tightened the public bundled skills surface: public releases now include only `hbi-*` skills and `hql-expert`; internal repo-maintenance skills and evaluation workspaces are not distributed.

## Upgrade

Use the installer from the public release surface:

```bash
curl -fsSL https://download.hengshi.com/cli/install.sh | sh
```

Or install this version explicitly:

```bash
curl -fsSL https://download.hengshi.com/cli/install.sh | sh -s -- --version 2.1.6
```
