# HENGSHI CLI 2.1.6

发布日期：2026-06-16

## 重点更新

- 改进仪表盘图表创建能力，补齐业务指标图表场景下的轴配置与字段处理。
- 加固图表 patch 行为，避免误删已有配置或写入无效缩放覆盖项。
- 修复图表选项处理，确保业务指标标识在创建和更新过程中稳定保留。
- 更新随包分发的 dashboard 与 HQL skills，补入最新图表轴和 Dashboard Plan 指南。
- 收紧 public release 的 bundled skills 范围：对外包只包含 `hbi-*` skills 和 `hql-expert`，仓库维护、评测工作区等内部 skills 不再随 public release 分发。

## 升级方式

使用 public release installer：

```bash
curl -fsSL https://download.hengshi.com/cli/install.sh | sh
```

或显式安装本版本：

```bash
curl -fsSL https://download.hengshi.com/cli/install.sh | sh -s -- --version 2.1.6
```
