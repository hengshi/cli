# HENGSHI CLI 2.1.7

发布日期：2026-07-01

## 重点更新

- 移除系统 keyring 后端依赖，`hbi auth login`、device login、token refresh、logout 与凭据清理统一使用 CLI 自有的 config-backed credential store。
- 减少 macOS 上因未受系统信任的本地构建访问 Keychain 而反复弹出密码确认的问题；正式版不再依赖系统 Keychain 保存 HBI 凭据。
- `--credential-store keyring` 作为兼容参数保留，但会明确提示该后端已移除；请省略该参数或使用 `--credential-store config`。
- 保持 installer 与 updater 的语义化版本兼容：安装包路径和 `latest.json.version` 仍使用 `2.1.7`。
- 发布版开始支持双版本号展示；日期 tag 发布时，`hbi --version` 会显示类似 `hbi 2.1.7 (v2026.7.1)`。

## 升级方式

使用 public release installer：

```bash
curl -fsSL https://download.hengshi.com/cli/install.sh | sh
```

或显式安装本版本：

```bash
curl -fsSL https://download.hengshi.com/cli/install.sh | sh -s -- --version 2.1.7
```
