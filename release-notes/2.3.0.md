# HENGSHI CLI 2.3.0

发布日期：2026-08-21

## 重点更新

- 增强数据模型查询能力，补充 chart-data 查询契约并支持排序参数，便于脚本和 agent 获取更稳定的查询结果。
- 增强业务指标维护能力，支持更新分析维度，并改进指标更新 / 删除时的 label 解析。
- 修复仪表盘 plan 导出与回放中的参数过滤器、嵌套 layout、按钮过滤器和按钮 patch 路径处理，提升复杂仪表盘配置的往返稳定性。
- 修复 app publish / republish 在不同后端 payload 形态下的解析与提交兼容性，减少发布配置缺字段或嵌套位置变化导致的失败。
- 修复图表 / 仪表盘异步导出轮询逻辑，避免 async-export 任务被误判为网络超时。
- 增强 public skills 中的仪表盘、数据建模和 HQL 使用说明，让 agent 在跨数据 app 参数、导出和查询场景下选择更准确的命令。

## 升级方式

使用 public release installer：

```bash
curl -fsSL https://download.hengshi.com/cli/install.sh | sh
```

或显式安装本版本：

```bash
curl -fsSL https://download.hengshi.com/cli/install.sh | sh -s -- --version 2.3.0
```
