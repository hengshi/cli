# HENGSHI CLI 3.0.0

发布日期：待定

## 兼容性

- 本版本需要配合 HENGSHI SENSE 7.0 使用。
- 数据填报、ChatBI 只读上下文、审计日志、Data Agent 运行时与沙箱相关命令依赖 7.0 的服务端接口，在 6.3 及更早版本上不可用。
- 本版本包含对 2.x 命令面的破坏性调整，升级前请阅读“破坏性变更”。

## 破坏性变更

- `hbi data-agent prompt ...` 已退役，不再提供 CLI 入口。
- `hbi data-agent vector init/status` 已退役，不再提供 CLI 入口。
- `hbi data-agent config verify` 已移除；校验请使用 `hbi data-agent config update --dry-run`。
- `hbi dataset example ...` 已移除，AI example 生成不再有独立的数据集子命令。
- `hbi data-agent config` 不再接受模型地址、模型名、API key、推理参数或 prompt 文本；模型配置改用 `hbi data-agent profile`。

## 重点更新

- 新增 `hbi survey` 数据填报命令族，覆盖填报模板与填报数据。
- 新增 `hbi audit` 操作记录查询。
- 新增 `hbi chatbi` 只读上下文命令，支持 scope、scope-candidates、model-candidates、dashboard-context 等 agent 场景。
- `hbi data-agent` 重组为 `config`、`profile`、`skills`、`operation` 四类后台治理命令。
- `hbi data-model` 支持表达式轴显式显示名 `--expr-label`、`value-search`，以及自动建模与角色引用。
- 仪表盘与图表能力增强：过滤控件 app 参数绑定、容器 tab 内图表发现、批量图表 patch、移动端分支持久化、逐图表解释信息。
- 修复 app publish / republish 的导出权限处理与首发布默认值。
- 新增 `hbi auth server-logout`，用于注销服务端会话。

## 升级方式

使用 public release installer：

```bash
curl -fsSL https://download.hengshi.com/cli/install.sh | sh
```

或显式安装本版本：

```bash
curl -fsSL https://download.hengshi.com/cli/install.sh | sh -s -- --version 3.0.0
```
