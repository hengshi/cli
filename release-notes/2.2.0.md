# HENGSHI CLI 2.2.0

发布日期：2026-07-17

## 重点更新

- 增强数据连接浏览能力，支持按精确 schema / table 路径浏览，方便在多 schema 数据源中定位目标表。
- 改进主题域与业务指标查询体验，支持按主题域标题查询，并优化指标展示中的 label / display name 解析。
- 加固数据集字段用途与连接来源处理，减少字段 purpose、连接来源等后端契约差异导致的创建或预览问题。
- 修复文件夹子资源区域保留逻辑，并补强跨文件夹指标、仪表盘复制与查询稳定性相关的 E2E 覆盖。
- 修复 Windows PowerShell installer 校验和解析问题，避免 `Select-String` 输出路径前缀时导致 hash 校验失败。

## 升级方式

使用 public release installer：

```bash
curl -fsSL https://download.hengshi.com/cli/install.sh | sh
```

或显式安装本版本：

```bash
curl -fsSL https://download.hengshi.com/cli/install.sh | sh -s -- --version 2.2.0
```
